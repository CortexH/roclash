# Bug — Unit PEACEFUL continua atacando automaticamente após destruir o alvo comandado

## Objetivo

Impedir que uma unit com comportamento `PEACEFUL` aceite novos intents automáticos de aggro depois de concluir um ataque solicitado pelo jogador.

Uma unit `PEACEFUL` deve aceitar `AggroIntent` somente quando:

```text
policy = COMMAND
e
origin.type = PLAYER
```

As duas condições são obrigatórias. Qualquer outra combinação deve resultar em `AggroIntentRejected` com `BEHAVIOR_NOT_ALLOWED`.

## Cenário para reproduzir

1. Spawnar uma unit com comportamento `PEACEFUL`.
2. Enviar um comando do jogador para atacar uma parede.
3. Aguardar a unit destruir a parede.
4. Observar a busca automática de aggro após a resolução do ataque.
5. A unit adquire e passa a atacar uma parede vizinha sem novo comando.

## Causa raiz

Depois que o alvo atual morre, `AttackResolvedEvent` produz um `UnitAggroSearchEvent`. A busca seleciona outro alvo e produz um `AggroIntent` com `policy = AUTO` e `origin.type = SYSTEM`.

O `AggroIntentSystem` validava o comportamento `PEACEFUL` apenas para intents com `origin.type = DAMAGE_RECEIVED`. Intents automáticos com origem `SYSTEM` chegavam ao `AggroValidator` e podiam ser aceitos.

## Resolução

Centralizar no `AggroIntentSystem` uma guarda para units `PEACEFUL`, antes da validação normal de aggro:

- aceitar somente `policy = COMMAND` junto de `origin.type = PLAYER`;
- rejeitar `AUTO + SYSTEM`;
- rejeitar `AUTO + DAMAGE_RECEIVED`;
- rejeitar combinações inconsistentes, como `COMMAND + SYSTEM` ou `AUTO + PLAYER`;
- preservar as regras existentes para `AGGRESSIVE` e `DEFENSIVE`.

## Critérios de aceitação

- [x] `PEACEFUL + COMMAND + PLAYER` pode aceitar um target válido.
- [x] `PEACEFUL + AUTO + SYSTEM` retorna `BEHAVIOR_NOT_ALLOWED`.
- [ ] `PEACEFUL + AUTO + DAMAGE_RECEIVED` retorna `BEHAVIOR_NOT_ALLOWED`.
- [ ] `PEACEFUL + COMMAND + SYSTEM` retorna `BEHAVIOR_NOT_ALLOWED`.
- [ ] `PEACEFUL + AUTO + PLAYER` retorna `BEHAVIOR_NOT_ALLOWED`.
- [x] Depois de destruir o alvo comandado, uma unit `PEACEFUL` não adquire automaticamente outro alvo.
- [ ] Units `AGGRESSIVE` e `DEFENSIVE` mantêm o comportamento existente.
